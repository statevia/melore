# 用語集

| 項目 | 値 |
| --- | --- |
| 種別 | Glossary |
| Version | 0.1 |
| 更新日 | 2026-11-04 |

Melore の文書で使う言葉の意味。対象リポジトリ（例: Statevia）の業務用語は、そのリポジトリの文書を正とする。

五十音・英字の順ではなく、**先に全体像、あとに部品**の順。

## 全体

| 用語 | 意味 |
| --- | --- |
| Melore | 仕様とコードを索引にして、エージェントが短い出典付き結果で調べられるようにするローカルサービス。対象リポジトリの中には入らない。 |
| 対象リポジトリ | 索引の対象になる Git リポジトリ。パスは `melore.json` の `repositoryPath`。 |
| コーパス | 実際に読み込むファイル一式（Markdown と C# など）。include / exclude で決める。 |
| インデックス | 対象を解析して SQLite に入れた検索用データ。元ファイルのコピー置き場ではない。 |
| 索引 DB | その SQLite ファイル。既定は `%LOCALAPPDATA%\Melore\<名前>.db`。 |
| `melore.json` | 対象パス・取り込み glob・Ollama 設定。example をコピーして作る。Git には載せない。 |
| CLI | 人が使うコマンド（`melore index` など）。発行先の例は `artifacts/melore/melore.exe`。 |
| MCP | エージェントがツールとして呼ぶ約束（Model Context Protocol）。Cursor からは子プロセスで起動する。 |
| stdio | 標準入力・標準出力で MCP のメッセージをやり取りする方式。**出力（stdout）はプロトコル専用。ログは stderr。** |
| Ollama | 手元で Embedding / チャットモデルを動かすデーモン。Melore はクライアント。 |

## 索引に入るもの

| 用語 | 意味 |
| --- | --- |
| チャンク（document chunk） | Markdown を見出し単位に切った検索の粒。パスと開始・終了行を持つ。 |
| 見出しパス（heading path） | そのチャンクが文書のどこにあるか。例: `Specifications / Fork Join`。 |
| シンボル | C# の型・メソッドなど。名前と完全修飾名（FQN）、定義の行範囲を持つ。 |
| FQN | 名前空間まで含む正式名。例: `Statevia.Core.Engine.Engine.ExecutionEngine`。 |
| テスト | `[Fact]` / `[Theory]` 付きメソッド。索引では kind が `test`。 |
| 関係（relationship） | チャンク同士・シンボル同士のつながり。仕様が型を指す、テストが型を試す、など。 |
| 出典 | ヒットが指すファイル相対パスと行範囲、および索引時の Git リビジョン。 |

## 検索と説明

| 用語 | 意味 |
| --- | --- |
| ヒット | 1 件の検索結果。必ずパスと行がある。 |
| snippet | ヒットの短い抜粋。既定はこれだけ返す（トークン節約）。 |
| 本文（body） | チャンクやシンボルの全文。MCP では `includeBody=true` のときだけ。 |
| `search` | 自然言語やキーワードで横断検索する。 |
| `references` | ある仕様・型のまわり（メンバー、テスト、文書リンクなど）を列挙する。 |
| `trace` | 型の所属・継承などを深さ制限つきでたどる。呼び出しグラフはまだない。 |
| `explain` | 検索上位だけを根拠に文章で説明する。索引に無い型名やパスは作らない。 |
| 根拠（grounded） | 返した文が、渡したヒットの中身に紐づいていること。 |
| FTS / FTS5 | SQLite の全文検索。単語（トークン）が本文に含まれるかを見る。 |
| Embedding | 文を数値の列（ベクトル）にしたもの。意味の近さで探す。 |
| ベクトル検索 | Embedding 同士の近傍検索。 |
| RRF | 全文・シンボル・ベクトルなど複数ランキングを足し合わせる方法（Reciprocal Rank Fusion）。 |
| Reranker | RRF のあとさらに並べ替える部品。初期は何もしない（専用モデルなし）。 |
| Hit@8 | ゴールデン 15 問のうち、上位 8 件に期待パスが入った割合。Phase 4 の目標は 0.9 以上。 |
| ゴールデンクエリ | 精度測定用の決まった質問と期待パス。`melore eval` が回す。 |

## 関係のラベル

| 用語 | 意味 |
| --- | --- |
| basis | 関係の根拠の確からしさ。`explicit`（規則でほぼ確定）か `inferred`（推定）。 |
| `specifies` | 仕様チャンクが、ある型の説明になっている、という関係。 |
| `tested_by` | 型が、あるテストメソッドで試されている、という関係。 |
| `contradicts` | 仕様のバッククォート名が、対応する型のメンバーに見当たらない、という矛盾候補（推定・低信頼）。 |
| `declares` | 型がメンバーを持つ。 |
| `inherits` / `implements` | 継承・インターフェース実装。 |

## 鮮度と解析

| 用語 | 意味 |
| --- | --- |
| リビジョン | 索引した時点の Git HEAD（SHA）。 |
| blob SHA | ファイル内容の Git ハッシュ。作業ツリー（未コミット含む）を見る。 |
| dirty | 索引時と内容が違うファイル。再解析対象。 |
| analyzer version | 各解析器が持つ版を Core が合成した文字列。変わると再解析・再埋め込みする。 |
| 差分インデックス | ハッシュが同じファイルは飛ばし、変わったものだけ入れ直す。 |
| Roslyn | C# 公式の構文解析。Melore は初期、コンパイルなしの構文だけ読む。 |
| n-gram | 文字の部分列で探す補助。日本語本文の漏れ対策候補。初期は未導入。 |

## ツールと設定の名前

| 用語 | 意味 |
| --- | --- |
| `index` | 対象を読んで索引を更新する。 |
| `status` | 件数・リビジョン・ベクトルの有無を出す。 |
| `eval` | ゴールデン Hit@8 を測る。 |
| `melore-mcp` | MCP サーバー実行ファイル。発行先は `artifacts/melore-mcp/melore-mcp.exe`。ログは stderr。 |
| ポート | 実装を差し替えるためのインターフェース（例: `IReranker`）。ネットワークのポートではない。 |
